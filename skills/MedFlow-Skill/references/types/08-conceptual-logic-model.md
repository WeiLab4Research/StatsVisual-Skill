# 08. 概念框架与干预逻辑模型

## 选择条件
按本图卡所述研究对象、表达目的和资料选择。优先入口见[8类分类](../taxonomy.md)；不匹配时使用[自定义方案](../custom-design.md)，不强行归类。

## 需要的研究信息
理论构念/背景、干预机制、投入、活动、产出、近期/远期结局、情境与反馈。每项记录材料出处；标记已提供、可推导、未知、不适用，不把未知画成零。关键条件缺失先在方案询问，不代做研究设计。

## 组织结构
概念框架按构念关系；逻辑模型按投入→活动→产出→结局，情境横跨。先列节点与有语义的关系，再安排坐标；不同对象/单位/时间范围保留独立标记。节点标签必须足以自解释；图题和解释性注释不入画布。

## 规范依据
复杂干预可参考MRC框架及TIDieR适用内容；无单一官方图式。阅读[规范映射](../standards/reporting-guidelines.md)以及目标期刊卡。并非每一类都有官方固定模板；不得宣称规范规定了全部方框或画法。

## 专用检查
两个子模式分别处理；产出不等于健康结局。假设关系与已验证关系区分；来源明确的逻辑反馈可以有环，不应被普通流程检查误判。
