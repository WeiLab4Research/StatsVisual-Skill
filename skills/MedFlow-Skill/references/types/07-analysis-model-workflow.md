# 07. 数据分析与模型开发验证流程图

## 选择条件
按本图卡所述研究对象、表达目的和资料选择。优先入口见[8类分类](../taxonomy.md)；不匹配时使用[自定义方案](../custom-design.md)，不强行归类。

## 需要的研究信息
分析目标/估计量、数据划分单位、预处理、缺失处理、变量构建、分析或建模、验证、敏感性分析。每项记录材料出处；标记已提供、可推导、未知、不适用，不把未知画成零。关键条件缺失先在方案询问，不代做研究设计。

## 组织结构
两个子模式：统计/因果分析流程；预测开发与验证流程。外部来源保留独立起点。先列节点与有语义的关系，再安排坐标；不同对象/单位/时间范围保留独立标记。节点标签必须足以自解释；图题和解释性注释不入画布。

## 规范依据
预测模型参考TRIPOD+AI 2024；其他分析按研究设计选规范。阅读[规范映射](../standards/reporting-guidelines.md)以及目标期刊卡。并非每一类都有官方固定模板；不得宣称规范规定了全部方框或画法。

## 专用检查
插补、标准化和特征选择的拟合限制在训练折内；调参与最终测试分开。随机留出不是外部验证；普通统计分析不强加训练/测试结构。
